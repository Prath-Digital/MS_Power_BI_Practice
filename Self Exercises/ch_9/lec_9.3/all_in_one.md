# Power BI Q&A (All-in-One Markdown)

## Q1. What is the difference between a bar chart and a column chart in Power BI?
**Answer:**
- A **bar chart** displays data using horizontal bars.
- A **column chart** displays data using vertical bars.
- Use bar charts when category names are long or when comparing many categories. Use column charts when comparing values over time.

---

## Q2. When should you use a donut chart instead of a bar chart?
**Answer:**
- Use a **donut chart** when showing **parts of a whole** with a small number of categories.
- It's mainly used for high‑level insights, not detailed comparison.

---

## Q3. What are the limitations of using a donut chart for visualizing data?
**Answer:**
- Hard to compare similar values accurately.
- Not suitable for large numbers of categories.
- Occupies more visual space while showing less information.

---

## Q4. What are the main types of filters available in Power BI?
**Answer:**
1. **Visual-level filters**
2. **Page-level filters**
3. **Report-level filters**
4. **Drill-through filters**
5. **Slicers (UI-based filters)**

---

## Q5. How do visual-level filters differ from page-level and report-level filters?
**Answer:**
- **Visual-level filters:** Affect only a single visual.
- **Page-level filters:** Affect all visuals on one page.
- **Report-level filters:** Affect all pages and all visuals.

---

## Q6. Describe how slicers are used as a filtering tool in Power BI reports.
**Answer:**
- Slicers provide an interactive, user-driven way to filter visuals.
- Users can select values (e.g., dates, categories) to update multiple visuals instantly.
- Good for dashboards needing dynamic exploration.

---

## Q7. What is the difference between a Table and a Matrix visual in Power BI?
**Answer:**
- **Table:** Flat, spreadsheet-style list of rows and columns.
- **Matrix:** Pivot-table style view allowing row groups, column groups, and drill-down.

---

## Q8. How can you drill down into data using a Matrix visual?
**Answer:**
- Add fields into **Rows**, **Columns**, or **Values** hierarchy.
- Enable **Stepped Layout** or **Expand/Collapse buttons**.
- Use the **drill-down arrows** in the visual header.

---

## Q9. What are the benefits of using Matrix visuals for hierarchical data?
**Answer:**
- Supports grouping and sub-grouping.
- Allows drill-down for deeper detail.
- Useful for financial and summary reports.

---

## Q10. What is conditional formatting in Power BI and why is it used?
**Answer:**
- Conditional formatting changes colors based on rules.
- Used to highlight trends, outliers, and performance indicators.

---

## Q11. Mention two ways to apply conditional formatting to a table or matrix.
**Answer:**
1. By **Color scale** (gradient based on value).
2. By **Rules** (e.g., values greater than X).

Other methods include icons, data bars, and field value formatting.

---

## Q12. How do you apply a Top N filter in Power BI to show only top-performing data items?
**Answer:**
**Steps:**
1. Open the **Filters** pane.
2. Select the field you want to filter by.
3. Choose **Top N** format.
4. Enter a number (e.g., Top 5).
5. Specify the value field used for ranking (e.g., Sales).
6. Click **Apply filter**.
